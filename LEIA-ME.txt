CORREÇÃO DE CAMINHO — GITHUB PAGES

Esta correção adiciona um 404.html compatível com GitHub Pages para que
rotas do aplicativo (por exemplo /login ou /callback) não parem na tela
404 do GitHub.

IMPORTANTE:
- O arquivo deve ficar na RAIZ do repositório, junto do index.html.
- Este é um patch de caminho. Ele não substitui a configuração OAuth do
  Google/Facebook.
- Se o provedor OAuth estiver configurado para um callback incorreto,
  ainda será necessário ajustar o URI de redirecionamento no provedor.

Base atual configurada:
