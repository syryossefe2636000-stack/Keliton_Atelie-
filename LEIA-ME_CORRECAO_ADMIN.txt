CORREÇÃO DO ACESSO DO ADMINISTRADOR — VERSÃO ATUAL

O projeto enviado pelo GitHub contém a estrutura do site + backend Node/WebAuthn.
O erro "Unexpected token < ... is not valid JSON" ocorre quando uma versão antiga
do JavaScript tenta chamar /api no GitHub Pages e recebe HTML/404.

Nesta correção:
- páginas *.github.io NUNCA chamam /api;
- o login por senha continua funcionando localmente no GitHub Pages;
- a biometria fica preparada e só chama o backend quando o site estiver servido
  pelo backend Node em HTTPS;
- removemos o registro normal do service worker no GitHub Pages e limpamos
  service workers/cache antigos que podem estar servindo uma versão velha;
- foi incluído um sw.js de autolimpeza como proteção adicional;
- a interface existente não foi redesenhada.

IMPORTANTE:
Para biometria WebAuthn real, Google/Facebook e persistência segura entre aparelhos,
o server.js precisa ser publicado em um serviço Node.js (por exemplo, Render) e o
site precisa apontar para o backend correto. Não coloque segredos no index.html.
